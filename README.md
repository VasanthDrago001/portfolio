# Portfolio

A personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS. It includes sections for projects, skills, experience, education, certifications, GitHub activity, and contact information.

## Requirements

- Node.js 20.19+ or 22.12+
- npm (included with Node.js)

The project uses Vite 8, which requires one of those Node.js versions. Check your installed versions with:

```sh
node --version
npm --version
```

## Setup

Open a terminal in the project folder, then install dependencies:

```sh
npm install
```

If you are using the included lockfile and want a reproducible install, run `npm ci` instead.

## Run locally

Start the development server:

```sh
npm run dev
```

Open the local URL printed in the terminal (Vite usually uses `http://localhost:5173`). The server updates the page as you edit files. Press `Ctrl+C` in the terminal to stop it.

## Build and preview

Create an optimized production build:

```sh
npm run build
```

The generated site is written to `dist/`. To serve that build locally for a preview:

```sh
npm run preview
```

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Type-check and create the production build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Check the source with ESLint |

## Project layout

- `src/components/` — portfolio page sections and UI components
- `src/App.tsx` — assembles the page
- `src/index.css` and `src/App.css` — global and application styles
- `public/` — static files served from the site root, including the resume and intro video
- `dist/` — production output generated by the build command

Static files in `public/` are referenced by their root URL. For example, `public/intro_video.mp4` is available as `/intro_video.mp4`.
