# Portfolio

A personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS. It includes sections for about, experience, skills, education, work highlights, and contact information.

## Requirements

- Node.js 20.19+ or 22.12+
- npm (included with Node.js)

The project uses Vite 8, which requires one of those Node.js versions. Check your installed versions with:

```sh
node --version
npm --version
```

## Setup

Clone the repository and enter the project folder. In Windows PowerShell, use the `.cmd` wrapper so PowerShell's script policy does not block npm:

```powershell
git clone <repository-url>
cd portfolio
Copy-Item .env.example .env.local
notepad .env.local
npm.cmd ci
```

In `.env.local`, set `VITE_EMAILJS_PUBLIC_KEY` to the public key from your EmailJS account. The local file is ignored by Git. On macOS/Linux, use `cp .env.example .env.local` and `npm ci`.

## Run locally

Start the development server:

```powershell
npm.cmd run dev
```

On macOS/Linux, run `npm run dev`. Open the local URL printed in the terminal (usually `http://localhost:5173`). Press `Ctrl+C` to stop the server.

## Build and preview

Create an optimized production build:

```powershell
npm.cmd run build
```

The generated site is written to `dist/`. To serve that build locally for a preview:

```powershell
npm.cmd run preview
```

## Available commands

| Command | Purpose |
| --- | --- |
| `npm.cmd run dev` | Start the local development server in Windows PowerShell |
| `npm.cmd run build` | Type-check and create the production build |
| `npm.cmd run preview` | Preview the production build locally |
| `npm.cmd run lint` | Check the source with ESLint |

## Project layout

- `src/components/` — portfolio sections and UI components
- `src/App.tsx` — assembles the page
- `src/index.css` and `src/App.css` — global and application styles
- `public/` — static assets, including the resume files and intro video
- `dist/` — production output generated by the build command

Static files in `public/` are referenced by their root URL. For example, `public/intro_video.mp4` is available as `/intro_video.mp4`.
